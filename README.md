# Nexa CRM — Demo interactiva

Demo de un CRM completo (contactos, empresas, negocios, citas, tareas, llamadas, informes, formularios, blog, redes sociales, tienda online y herramientas de desarrollo).

- **Todos los datos son ficticios.** No hay servidor: todo se simula en el navegador.
- Los cambios que hagas se guardan solo en tu navegador (localStorage). El botón «Restablecer datos» de la barra superior vuelve al estado inicial.
- Marca, nombres, correos y empresas son inventados (dominios `.example`).

## Ejecutar en local
```
npm install
npm run dev      # http://127.0.0.1:5174
npm run build    # genera dist/ (estático, listo para cualquier hosting)
```

Stack: React 19 · Vite · Tailwind 4 · React Router (hash).
